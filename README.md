# Инетрнет магазин Megano

Megano - это платформа для онлайн-торговли, разработанная на Django. Проект позволяет владельцам магазинов быстро
переносить свои товары в онлайн, обеспечивая полный цикл: от каталога до оформления и оплаты заказа.

## Развертывание 

Проект спроектирован как «легкопереносимый». Для запуска используйте стандартный менеджер пакетов pip и команды 
управления Django.

```bash
    # Клонирование репозитория
    git clone https://gitlab.skillbox.ru
    
    # Настройка окружения
    # Обязательно укажите свои настройки в .env
    cp .env.example .env
    
    # Установка зависимостей (если есть requirements.txt)
    pip install -r requirements.tx
    
    # Подготовка базы данных (создание таблиц, ролей и администратора)
    python manage.py migrate
    
    # Загрузка тестовых данных (фикстур) для демонстрации
    python manage.py loaddata shop_fixtures.json
```

## Запуск

```bash
    python manage.py runserver 0.0.0.0:8000
```

## Основные возможности
 - **Каталог**: Фильтрация по цене/бренду и сортировка по популярности (количеству покупок). 
 - **Заказы**: Пошаговое оформление с выбором типа доставки (Обычная/Экспресс) и способа оплаты.
 - **Оплата**: Интеграция с фиктивным сервисом оплаты через очередь задач.
 - **Админка**: Полное управление товарами и заказами через Django Admin (доступно только для персонала).
